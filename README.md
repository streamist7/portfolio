**English**

## 업무 원칙 | Working Principles

1. **검증 후 완료 판단 | Verify before claiming completion**  
   한국어: 빌드나 테스트 통과는 실제 운영 환경의 검증 완료와 다릅니다.  
   English: Passing a build or test is not equivalent to validated production behavior.

2. **원본과 상태의 구분 | Maintain a clear source of truth**  
   한국어: 코드, 의사결정, 실험 증거, 실제 배포 상태를 구분해 관리합니다.  
   English: Keep code, decisions, experimental evidence, and deployed state distinct.

3. **데이터 및 운영 환경 보호 | Protect data and operations**  
   한국어: 실제 영향을 미치는 변경은 위험과 권한에 맞춰 검토합니다.  
   English: Review impactful changes according to their risks and permissions.

4. **책임 있는 AI 활용 | Use AI responsibly**  
   한국어: AI 도구를 개발 업무에 활용하되, 실제 역할과 검증 범위를 명확히 밝힙니다.  
   English: Use AI as a development tool while clearly stating responsibilities and validation boundaries.
