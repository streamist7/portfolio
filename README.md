**Product Strategy · AI-Assisted Software Development · Research**

디지털 제품의 기획부터 AI 기반 개발 운영, 품질 검증, 연구·실증까지 연결하는 일을 합니다. 검증된 결과와 아직 확인되지 않은 사항을 구분하고, 안정적인 운영과 재현 가능한 의사결정을 중요하게 생각합니다.

Selected digital products and research projects are developed in **private repositories**. Public case studies, screenshots, and demonstrations will be added only after a disclosure and confidentiality review.

현재 개발 중인 제품과 연구의 원본 저장소는 비공개로 유지합니다. 외부 공개가 승인된 기능 소개, 화면, 구조도, 검증 성과만 별도 포트폴리오로 제공합니다.

## Working Principles | 업무 원칙

1. **Verify before claiming completion.** Passing a build or test is not the same as production validation.
2. **Keep the source of truth clear.** Code, decisions, experiments, and deployed states are tracked separately.
3. **Protect operational systems and private data.** Changes with real-world impact require proportionate review.
4. **Use AI as an engineering tool, not a substitute for accountability.** State responsibilities and validation boundaries accurately.
